# E-Commerce Sales & Customer Analytics

## Project Overview
An end-to-end data analytics project focused on analyzing
e-commerce sales, customer behavior, and product performance
using SQL and Power BI.

## Tools & Technologies
- MySQL Workbench
- Power BI Desktop
- Microsoft Excel
- SQL

## Project Objectives
- Analyze overall sales and order performance.
- Identify top-performing products.
- Understand customer purchasing behavior.
- Analyze monthly and quarterly sales trends.
- Explore country-wise sales performance.

## Project Structure
- Dashboard_Screenshots: Power BI dashboard images
- data: Dataset files
- insights: Business insights
- processed: Cleaned dataset
- sql: SQL queries
- Ecommerce_PowerBI.pbix: Power BI dashboard

## Dashboard Pages
1. Executive Overview
2. Customer Analysis
3. Product Performance Analysis
4. Sales Trends & Time Analysis

## Key Features
- Interactive dashboards
- KPI cards
- Date and country slicers
- Customer and product analysis
- Sales trend analysis
